# STRINGR Website Development Skill & Learning Program

A reusable package for training the STRINGR team and standardizing AI-assisted website development.

## Package contents
- `SKILL.md` — reusable instructions for an AI coding agent.
- `LEARNING_PATH.md` — staged developer learning program.
- `CURRICULUM/` — practical learning modules and exercises.
- `WORKFLOW/` — project workflow, review gates, and delivery checklist.
- `PROMPTS/` — reusable prompts for planning, implementation, review, and debugging.

## How to use this package

### For AI coding agents
1. Copy `SKILL.md` into the agent's supported skills location or keep it in the project documentation.
2. Ensure the project also has its approved `AGENTS.md` and planning documents.
3. Ask the agent to follow the skill and the project's instructions.
4. Treat project-specific approved documents as the source of truth. The skill does not override them.

### For team learning
1. Start with `LEARNING_PATH.md`.
2. Complete the modules in order, adapting depth to each team member's role.
3. Build the capstone website in a development environment.
4. Require code review, testing, and a documented handover.

## Important operating rule
This package is a baseline, not a fixed technology mandate. Select and approve the stack for each project in `03_TECH_STACK.md`. Do not assume every website needs the same backend, database, CMS, or hosting platform.
