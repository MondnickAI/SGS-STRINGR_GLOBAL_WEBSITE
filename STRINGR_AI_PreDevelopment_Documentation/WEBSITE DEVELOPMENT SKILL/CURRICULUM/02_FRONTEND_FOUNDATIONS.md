# Module 02 — Frontend Foundations

## Learning outcomes
- Build semantic HTML structure.
- Apply CSS layout with Flexbox and Grid.
- Create responsive layouts.
- Implement accessible navigation and forms.

## Practical exercise
Build a responsive company landing page with header, hero, services, testimonials, and contact section using approved brand references.

## Acceptance checks
- Works at mobile, tablet, and desktop widths.
- Uses semantic headings and form labels.
- Keyboard focus is visible.
- Images have appropriate alternative text.
- No horizontal overflow at supported widths.
