# Module 05 — Backend, APIs, and Data

## Learning outcomes
- Understand HTTP methods, status codes, and JSON.
- Read and follow an API contract.
- Validate data on the server.
- Understand relational tables, keys, and migrations.
- Distinguish authentication from authorization.

## Practical exercise
Create a test RFQ submission flow. Validate the request, store test data if a database is in scope, and show a confirmation state.

## Acceptance checks
- Server validates input independently of the browser.
- Errors use documented responses.
- Secrets are not exposed to frontend code.
- Protected operations enforce permissions server-side.
