# Module 03 — JavaScript and TypeScript

## Learning outcomes
- Write functions and modular JavaScript.
- Work with arrays, objects, events, and asynchronous operations.
- Handle errors and validate data.
- Use TypeScript to describe data and reduce unsafe assumptions.

## Practical exercise
Create a searchable services list and a form that validates required fields, email format, and user consent before submission.

## Acceptance checks
- Invalid data is handled clearly.
- Async failures do not crash the interface.
- Types describe the data being used.
- Logic is organized into understandable functions.
