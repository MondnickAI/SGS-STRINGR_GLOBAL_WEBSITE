# Module 07 — AI-Assisted Engineering

## Learning outcomes
- Use project planning documents and `AGENTS.md` as context.
- Write scoped prompts with acceptance criteria.
- Ask for a plan before non-trivial changes.
- Review AI-generated diffs and test results.
- Identify invented assumptions, unsafe changes, and unnecessary dependencies.

## Practical exercise
Ask an AI coding agent to add one approved feature to the capstone:
1. Provide relevant project documents.
2. Ask for a plan and risks.
3. Review and approve the plan.
4. Ask for implementation.
5. Inspect the diff.
6. Run verification.
7. Record what you accepted or rejected.

## Acceptance checks
The learner can explain the implementation, identify limitations, and prove that relevant checks were run.
