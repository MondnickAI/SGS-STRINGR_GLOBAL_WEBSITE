# Module 01 — Web Foundations

## Learning outcomes
- Explain the roles of browser, server, HTTP, DNS, and hosting.
- Navigate a codebase and use the terminal.
- Run a local project and inspect browser errors.
- Use Git to track a small change.

## Practical exercise
1. Create a simple project folder.
2. Add an HTML page, stylesheet, and JavaScript file.
3. Run it locally using the team's approved tooling.
4. Inspect the page with browser developer tools.
5. Initialize Git, inspect the diff, and commit the work.

## Review questions
- What happens when a user enters a website URL?
- What is the difference between a browser error and a server error?
- Why should changes be committed in small, understandable units?
