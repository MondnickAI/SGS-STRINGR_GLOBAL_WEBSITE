# Module 04 — Frameworks and Components

## Learning outcomes
- Follow the framework chosen in the project stack.
- Build routes, layouts, and reusable components.
- Manage component state and data loading.
- Display loading, empty, success, and error states.

## Practical exercise
Convert the landing page into a multi-page site with shared header/footer and reusable service cards.

## Acceptance checks
- Navigation works.
- Components have focused responsibilities.
- Shared UI is not unnecessarily duplicated.
- Pages follow the approved UI/UX specification.
