# Module 06 — Quality, Security, and Deployment

## Learning outcomes
- Choose tests for critical user journeys.
- Run lint, type checks, tests, and production builds.
- Identify common web security risks.
- Understand staging, production, backups, monitoring, and rollback.

## Practical exercise
Test the RFQ journey, deploy to a staging environment, inspect logs, and write a rollback note.

## Acceptance checks
- Critical path has repeatable tests.
- No secrets are committed.
- Authorization is checked on the server.
- Deployment and recovery steps are documented.
