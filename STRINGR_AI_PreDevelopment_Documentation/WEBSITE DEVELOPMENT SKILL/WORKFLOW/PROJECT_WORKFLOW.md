# STRINGR Website Project Workflow

## Gate 1 — Discovery and scope
- Collect client brief and existing materials.
- Confirm objectives, users, MVP, exclusions, and acceptance criteria.
- Record open questions, constraints, and risks.
- Obtain scope approval.

## Gate 2 — Design and technical planning
- Prepare UI/UX specification.
- Evaluate and approve the technology stack.
- Define architecture, data model, API contracts, and security needs.
- Prepare project-specific `AGENTS.md` and decision log.
- Obtain technical approval.

## Gate 3 — Repository and environment
- Initialize Git and branch conventions.
- Configure runtime, package manager, environment examples, and ignore rules.
- Configure linting, type checking, tests, and build checks.
- Confirm no secrets are committed.

## Gate 4 — Incremental implementation
- Implement one approved feature/module at a time.
- Review plan and diff.
- Verify behavior and update tests/docs.
- Commit coherent, verified changes.

## Gate 5 — QA and release readiness
- Test critical user journeys and responsive layouts.
- Review accessibility, security, performance, and content.
- Confirm production configuration, backup, monitoring, and rollback.
- Obtain release approval.

## Gate 6 — Handover and maintenance
- Provide setup and deployment documentation.
- Transfer credentials securely through approved channels.
- Explain known limitations and maintenance responsibilities.
- Confirm ownership of hosting, domains, integrations, and support.
