# Website Development — Definition of Done

A feature is complete only when applicable items below are satisfied.

## Requirements
- [ ] Approved requirement and acceptance criteria are met.
- [ ] Scope changes are documented and approved.

## Implementation
- [ ] Follows approved stack and architecture.
- [ ] Reuses established components and patterns.
- [ ] Handles loading, empty, success, and error states as relevant.
- [ ] Does not introduce unexplained dependencies or unrelated changes.

## Quality
- [ ] Lint and formatting checks pass.
- [ ] Type checks pass where applicable.
- [ ] Relevant automated tests pass.
- [ ] Production build succeeds.
- [ ] Responsive behavior is checked.

## Security and accessibility
- [ ] Server-side authorization is applied where required.
- [ ] No secrets or sensitive test data are exposed.
- [ ] Inputs and uploads are validated where applicable.
- [ ] Keyboard, labels, focus, and contrast are reviewed.

## Delivery
- [ ] Documentation and environment examples are updated.
- [ ] Diff is reviewed.
- [ ] Changes are committed according to project workflow.
- [ ] Remaining limitations and risks are reported.
