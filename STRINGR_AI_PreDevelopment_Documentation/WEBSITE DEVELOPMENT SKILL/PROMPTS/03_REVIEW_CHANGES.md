# Prompt — Review AI-Generated Changes

Review the current uncommitted diff against the task requirements and project instructions.

Check:
1. Functional correctness and acceptance criteria.
2. Architecture and maintainability.
3. Security, privacy, and authorization.
4. Accessibility and responsive behavior.
5. Error handling and edge cases.
6. Tests and documentation.
7. Unnecessary changes or dependencies.

Do not modify files during the review. Report findings by severity with file references and recommended fixes. Distinguish confirmed defects from possible risks.
